# 🌍 TravelFlow AI – Smart Travel Planner

## 📌 About the Project

TravelFlow AI is a smart travel planning platform designed to make travelling easier, more organized, and more enjoyable. The platform helps users discover exciting destinations, plan personalized trips, organize daily itineraries, and manage travel expenses in one place.

The main goal of this project is to simplify the travel planning process through an interactive and user-friendly interface. Users can explore popular destinations, choose their preferred travel locations, enter trip details, organize activities, and monitor their travel budgets.

TravelFlow AI aims to provide a convenient travel planning experience by combining modern web technologies with intelligent travel planning concepts.

## 🎯 Project Objectives

- To provide a simple and user-friendly travel planning platform.
- To help users discover popular destinations and interesting places.
- To allow users to create personalized travel plans based on their preferences.
- To organize travel activities into daily itineraries.
- To help users estimate and manage travel expenses.
- To provide an attractive and responsive user interface.
- To explore the use of Artificial Intelligence in personalized travel recommendations.

## ✨ Key Features

### 🏠 1. Home
Provides a welcoming dashboard with popular destinations, recommended places, and quick access to the main features of the application.

### 🔍 2. Explore Destinations
Allows users to discover travel destinations with images, destination details, estimated costs, and categories such as adventure, nature, beaches, and culture.

### ✈️ 3. Plan My Trip
Allows users to enter their destination, travel dates, number of travellers, estimated budget, and travel preferences to organize a personalized trip.

### 🗺️ 4. My Itinerary
Displays a structured travel schedule divided into morning, afternoon, and evening activities. Users can organize places to visit and view estimated activity costs.

### 💰 5. My Budget
Helps users monitor their estimated travel expenses, including transportation, accommodation, food, and activities. It also displays the remaining budget to support better financial planning.
