# 🌍 TravelFlow AI — Smart Travel Planner

An AI-powered Smart Travel Planner website that helps users explore destinations, plan trips, generate itineraries, and manage travel budgets.

## ✨ Features

- 🏠 Home — Discover popular destinations.
- 🔍 Explore — Search and explore travel destinations.
- ✈️ Plan My Trip — Create personalized trip plans.
- 🗺️ My Itinerary — Organize daily travel activities.
- 💰 My Budget — Track travel expenses.

## 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- UI Design: Google Stitch
